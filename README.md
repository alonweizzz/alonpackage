# Alon — Personal Website

Responsive Hebrew portfolio with liquid-glass design, dark mode by default, optional light mode, and project showcases.

## Local preview
Open `index.html` in any browser. No installation needed.

## Deploy on GitHub Pages
Visit **Settings → Pages**, choose **Deploy from a branch**, select **main / (root)** and save.

Note: this repository is currently private. Pages publishing depends on GitHub plan and repository visibility.

## Customize
Edit `index.html` for descriptions and links, `style.css` for design, and `script.js` for behavior. The hero logo lives at `assets/alon-logo.jpg`.
